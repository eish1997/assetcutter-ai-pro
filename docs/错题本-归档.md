## 2026-06（详述）

### 2026-06-04: 重启后分镜表卡片仍消失（IDB-only + 首屏 autosave 竞态）

- **现象**：本地重启/整页刷新后，工作区分镜表卡片整块不见，其他类型卡片仍在。
- **原因**：bundle 已落 IndexedDB 后 localStorage 常为空；首屏 React 状态先空，650ms autosave 可能把**缺 `storyboard_table` 的 bundle** 写回 IDB。原有 `resolveExistingAssetsForPersistGuard` 只读 cache + localStorage，**读不到 IDB 里的分镜表**，补回失效。另：`loadComplete` 在项目切换 effect 里被重置，可能在加载完成后误关 autosave 门闩。
- **修复**：`storyboardPersistGuardByKey`；`resolveExistingAssetsForPersistGuard` 合并 guard + cache + raw；`App.tsx` `workflowProjectLoadCompleteRef` 仅在 load 首尾控制；测试 guard-only 补回。
- **涉及**：`services/workspaceProjectStore.ts`、`App.tsx`、`tests/workspaceProjectStore.test.ts`

### 2026-06-02: 工作区旧分镜表「消失」/ 只能新建

- **现象**：刷新或改代码后，工作区列表里原有分镜表卡片不见，只剩「新建分镜表」可用；**图片/文字等其他类型资产卡片仍在**。
- **原因**：React 状态/autosave 在某一时刻缺少 `storyboard_table` 条目，把「仍有其他卡片的 bundle」写回 IDB；或云 merge / sanitize 异常导致分镜表条目从数组中丢失。
- **修复**：`mergePreservingStoryboardTableAssets`；`shouldBlockEmptyWorkflowBundlePersist`；sanitize 单条失败保留原 asset；云 merge 补 local-only 分镜表；缺 `assetKind` 自动识别。
- **涉及**：`services/workspaceProjectStore.ts`、`App.tsx`、`services/workflowBundleSanitize.ts`、`services/workflowBundleMerge.ts`

### 先切分后加文本，分镜内切好的图全丢

- **现象**：切分回填后粘贴/解析分镜文本，编辑页各镜图变空。
- **原因**：文本导入 replace 仅按镜号匹配；append 未匹配时插入新行；`commitImport` 可能读到切分完成前的旧 rows。
- **修复**：镜号匹配失败则按「已有分镜图行顺序」对齐；append 优先原地更新仅有图行；BulkInput 用 `rowsRef`。
- **涉及**：`storyboardTableBulkImport.ts`、`storyboardTableParse.ts`、`StoryboardTableBulkInput.tsx`
