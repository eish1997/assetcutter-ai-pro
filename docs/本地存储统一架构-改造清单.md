# 本地存储统一架构 — 改造清单（伴侣优先）

**定位**：把「看得见预览」和「可打开本机文件夹 / 可重开不丢」收敛到同一套本地真相；**执行主清单**以本文为准。  
**适用对象**：前端工作台、本地伴侣、联调测试。  
**关联文档**：
- `docs/本地与云存储分层开发方案.md`（原则与分层；§0.1 指向本文）

- `docs/工作流3D落盘与下载优化.md`

## 一句话目标

**伴侣项目目录 = 完整本地真相；浏览器 IDB = cache；云端 = 索引/显式 pin。**  
短期不追求 MediaRef 大迁移或 CRDT；优先收口：**写入时序、删死门面、一条水合路径、一张「谁赢」规则表**。

## P0：收口（必须先做，否则统一是假的）

### P0-1 项目 boot barrier（写屏障）

**目标**：伴侣快照 / manifest 恢复完成前，禁止该项目 IDB autosave 与 companion PUT。

| 项 | 内容 |
| --- | --- |
| 改哪里 | `App.tsx` 打开项目链路；autosave effect；`putCompanionWorkflowSnapshot` 调用点 |
| 做法 | 每项目 `bootGeneration` / `companionHydrateReady`；恢复完成前 `skipAutosave`；旧 async 带 generation 校验 |
| 完成标准 | 人为延迟 companion GET 时，旧 IDB 不能 PUT 覆盖伴侣；单测或脚本可复现「慢 GET 不丢伴侣」 |
| 状态 | ✅ 已做（`services/workflowProjectBootBarrier.ts`；App autosave/flush 门控；`tests/workflowProjectBootBarrier.test.ts`） |

### P0-2 死门面二选一：删或真切

**目标**：消灭「统一入口」误导。

| 选项 | 动作 |
| --- | --- |
| A（推荐优先） | 删除或降级为 re-export 注释「未接线」：`workflowMediaPersistence.ts`、`workflowMediaHydrate.ts`；MediaRef 仅保留 Locator 所需的 collect 工具，砍掉无消费者投影写回 |
| B | 一周内把 `WorkflowSection` / persist schedule / lazy hydrate **全部**改为只走脊柱模块，旧直连禁止新增 |

| 项 | 内容 |
| --- | --- |
| 完成标准 | `rg` 证明：生产路径只有一条写盘入口、一条 raster hydrate 入口；或死文件已删除 |
| 状态 | ✅ 已做（选项 A：删除 `workflowMediaPersistence.ts` / `workflowMediaHydrate.ts`；`workflowMediaRef` 仅保留 collect + active key） |

### P0-3 水合只留一条活路

| 项 | 内容 |

### P0-4 「谁赢」唯一决策表

| 项 | 内容 |

## 同卡当前输出（显示态 = displayKey 槽模态）

**一句话**：`assetKind` 只表出生壳；对外只认 `displayKey` 指向的槽（文/图/视频/3D）；始终一张卡，只换预览。

| 项 | 内容 | 状态 |
| --- | --- | --- |
| 裁决入口 | `resolveWorkflowDisplaySlot`（`workflowTextAsset.ts`）；同一 key 禁止双读 textResults+results | ✅ |
| 写回 | 文生图写同卡 `results[step]` + `scheduleCompanionPersistResult`（含 https import-url）；不新建图卡 | ✅ |
| 读路径 | 预览/拖入/门禁/execute/打开文件夹跟当前槽；禁止 `isWorkflowTextAsset` 一票否决图身份 | ✅ |
| 打开文件夹补洞 | 有显示栅格无键时按需写 `resultsCompanionKeys` 再 reveal（`workflowEnsureCompanionForReveal`）；复制跟显示槽 | ✅ |
| 水合 | text 出生卡开放 `resultsCompanionKeys` 图槽；**不**把生产图灌进 text 的 original | ✅ |
| 已废止 | 写时拆卡 / migrate strip 升格 / `TEXT_SHELL_*` 硬拒绝派生图卡 | — |

验收：文字卡文生图后仍一张卡且可拖图能力；Q/E 切回正文；单测 `tests/workflowTextAsset.test.ts`。

## 明确不做（防回潮）

- 不上 CRDT / 事件溯源 / SQLite「再造真相」掩盖竞态。
- 不再平行新建第二套 MediaRef 数据库或第四条 hydrate effect。
- 不默认自动 R2 归档全量 3D/大图当本地替代。
- 不对 manifest、workflow、IDB 做三方「智能字段级合并」。
- 不以「再修一个灰按钮」宣布架构完成。
- **不再「写时拆卡」或打开项目 strip 升格新图卡。**
- **不为修灰按钮给文字出生壳伪造 original 图 locator（图在 results 槽）。**
