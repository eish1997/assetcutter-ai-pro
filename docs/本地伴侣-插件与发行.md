# 本地伴侣：插件能力 vs 发行资产

本文固定两套概念的**命名与更新路径**，避免与「设置 → 功能区 / 工作流里调用的能力」混淆。

## 1. 概念对照

| 名称 | 含义 | 典型形态 | 更新是否要重装桌面壳 |
|------|------|----------|----------------------|
| **运行时插件 / 能力** | `local-companion` 在 `/v1/capabilities` 宣告的服务（存储、计算、后续如 Segment Anything 子进程等） | 由宿主进程加载或子进程提供 | **不必**。由宿主拉取插件包、重启 **Node 伴侣进程** 即可；Electron 仅负责托盘与拉起宿主。 |
| **桌面壳（Electron）** | `companion-desktop` 安装包 / 便携 exe | `.exe`、NSIS、portable | **需要新壳** 仅当改了 Electron 层（托盘、IPC、向导、自动更新逻辑等）。 |
| **宿主插件包（host_plugin_bundle）** | 预置给 `local-companion` 解压加载的 ZIP/目录（含 Python 环境、模型权重等） | 大体积 artifact | **不必**重装壳；登记为 `host_plugin_bundle`，由宿主侧更新与校验（规划：下载至 volume、manifest、重启宿主）。 |

**Segment Anything 等开源能力**：建议作为 **宿主侧子进程或独立 runtime 目录**，由 `local-companion` 配置路径与健康检查；更新走 **host_plugin_bundle** 或专用拉取管道，与 **桌面壳安装包** 分离。

## 2. 主站「发行」功能（已实现骨架）

- **管理后台**：`/admin/companion-artifacts`（**本地伴侣发行**）— 管理员预签名上传至 R2 前缀 `public/companion-distribution/`，登记 `semver`、平台、渠道、`sha256` 等；上传时浏览器会同时计算 **`sha512`（hex）** 并写入登记（可选用于 **electron-updater** 的 `latest.yml`）。
- **删除**：`DELETE /api/admin/companion-artifacts/:id` 在 R2 已配置时**先删对象再删元数据**；若 R2 删除失败则整笔不删并返回 502。
- **元数据存储**：若进程配置了 **`DATABASE_URL`**（如 Render 上的 auth-api），则存 **Postgres 表 `companion_artifacts`**，避免每次部署清空临时磁盘导致「全站看不到已发布安装包」。未配置时回退为 **`server/data/companion-artifacts.json`**（本地开发常见；首条登记时自动创建）。
- **公开摘要**：含 `sha256`、`bytes`，供本机宿主安装时做完整性校验。
- **用户下载桌面壳**：登录用户在工作区侧栏底部「伴侣」区域可下载 **`desktop_shell`** 最新 **stable** 包（按浏览器推断 `win32` / `darwin` / `linux`）。
- **宿主插件包落盘（local-companion）**：
  - `GET /v1/host-plugins/bundles` — 已安装列表（`manifest` + `bundlePath` 等）；若存在 **`extracted/run.json`** 且解析成功，每条带 **`runSpec`**（`schemaVersion: 1` 与 `probe`/`exec` 等，见下文 **§4**）。
  - `POST /v1/host-plugins/install-from-url` — Body：`{ url, semver, sha256, bytes, label? }`；从 **https** URL 流式下载、校验大小与 SHA256，写入卷内。URL 主机须为 `*.r2.cloudflarestorage.com` / `*.r2.dev`，或在环境变量 **`COMPANION_HOST_BUNDLE_TRUST_HOSTS`**（逗号分隔）中追加；体积上限默认 512MB，可用 **`COMPANION_HOST_BUNDLE_MAX_BYTES`** 调整。响应含 **`runSpec`**（安装后即时解析）。
  - **主站设置 → 本地伴侣**：「安装最新宿主插件包到本机」会串联 `resolve-download` 与上述接口（需登录、本机伴侣可达、Bearer 一致）；同区块提供 **刷新已安装包列表**、下拉选择包、**运行 probe/exec**（调用 **`POST /v1/compute/jobs`**，类型 **`host_bundle.probe` / `host_bundle.exec`**），并把 **`jobId` 填入「任务进度」** 以便 SSE/轮询（见 **`docs/本地伴侣-本地程序开发.md`** §3 / §4.1）。**`services/companionClient/hostPlugins.ts`**、`compute.ts` 封装对应 HTTP。
- **API**（auth-api，需已配置 R2）：
  - `GET /api/companion-artifacts/catalog` — 公开摘要列表；
  - `GET /api/companion-artifacts/latest?kind=&platform=&channel=` — 最新一条摘要；
  - `POST /api/companion-artifacts/resolve-download` — 需登录，返回短时 GET 预签名 URL；跨域静态站与 **`/api/r2` 相同**不在此路径做双端 CSRF 头校验（依赖白名单 `Origin` + 会话 Cookie）。
  - **`GET /api/companion-artifacts/electron-app-update.yml`** — 查询参数与 **`latest`** 一致（`kind` / `platform` / `channel`），返回 **electron-updater generic** 用 YAML；服务端须配置 **`COMPANION_DIST_PUBLIC_HTTP_BASE`**（公网可读对象 URL 前缀，无尾斜杠），与 R2 对象 **`r2Key`** 拼接成下载 URL；YAML 内 **`sha512`** 为 **Base64**（由登记 hex 转换），见 **`server/companion-electron-feed.js`**；
  - 管理端：`GET/POST/DELETE /api/admin/companion-artifacts`、`POST /api/admin/companion-artifacts/upload-url`。

## 3. 安全与运维注意

- 对象键必须为 `public/companion-distribution/` 前缀；下载仅在**登记记录存在**时服务端代签 URL，避免任意 key 泄露。
- 管理端删除发行记录时，若 R2 已配置，会**同步删除对象**后再删元数据（失败则保留元数据并返回错误）。
- 大文件注意 R2 出站流量与浏览器超时；后续可接 **CDN / 分块 / 壳内 updater**（`COMPANION_UPDATE_FEED_URL` 见 `companion-desktop/README.md`）。

## 4. `run.json` 与计算接入（已实现）

- **`host_plugin_bundle` + ZIP**：若 `bundle.bin` 为 ZIP（魔数检测），安装后自动解压到 **`extracted/`**，`manifest.json` 记 `bundleFormat: zip`、`extractedRelativeDir: "extracted"`（实现见 **`local-companion/src/hostPluginBundles.ts`**，**zip-slip** 防护）。
- **`extracted/run.json`（RunSpec v1）**：**`schemaVersion: 1`**；可选 **`description`**；**`cwd`** 相对 extracted 根；**`probe` / `exec`** 各含 **`command: string[]`**，可选 **`cwd`**、**`env`**（值须为字符串）。解析见 **`local-companion/src/hostBundleRunSpec.ts`**。
- **计算任务**：**`host_bundle.probe`** / **`host_bundle.exec`** 仅接受 **`inputs: { dirName }`**（与 `host-bundles` 下目录名一致）；**命令行不得来自浏览器请求体**，仅来自磁盘 **`run.json`**。适配器 **`host_bundle@v0.1.0`**，超时 **`COMPANION_HOST_BUNDLE_EXEC_TIMEOUT_MS`**。详见 **`docs/本地伴侣-本地程序开发.md`** §3、§4.1 与 **`docs/本地伴侣-存储与计算规范.md`** §5。
- **`/v1/capabilities`**：除静态插件表外，动态追加 **`plugin.host_bundle.<目录名>`**；`detail` 会提示是否已解析 **run.json**、是否含 **exec/probe**。
- **electron-updater**：登记 **`sha512`（hex）** 后，**`electron-app-update.yml`** 与桌面壳 **`COMPANION_UPDATE_FEED_URL`**（`electron-builder` generic）可共用同源版本元数据；公网基址 **`COMPANION_DIST_PUBLIC_HTTP_BASE`** 须与实际上传对象的可读 URL 一致。

**桌面壳**：已具备按「设置中的网站地址」轮询 `GET /api/companion-artifacts/latest?kind=desktop_shell`（约 45s 后首次，之后每 4h），若远端 **semver** 高于 `companion-desktop/package.json` 的 **version**，托盘气泡提示可到主站工作区左下角下载（与 `COMPANION_UPDATE_FEED_URL` 自动更新可并存）。

## 5. 后续可演进

- **工作流一键触发 `host_bundle.exec` / `host_bundle.probe`（已实现）**：能力预设可选字段 **`companionHostBundle`**（`dirName`、可选 `phase`）；`executeCapability` 在 **`services/capabilityExecutor.ts`** 内向本机伴侣 **`POST /v1/compute/jobs`**；工作区队列与能力集合执行时附带 **`companionProjectId`**（当前工作区项目 id）。配置入口：**能力预设** 编辑区「本机伴侣 · 宿主包」；拖入图片或文字卡均可触发（见 **`workflowAssetAllowedForCapabilityDrop`**）。若集合末级为纯 **`host_bundle`** 文字节点且无下游生图，**输出节点**可能缺少图像输入，需自行构图。
- 更强隔离：宿主包子进程 **资源上限**、**并发队列**。
