# 本机分割（SamLocal）故障排除

面向使用 **工作区大图 · 本机分割** 的用户与排障。权威契约见 **`docs/本地伴侣SAM分割-产品开发规格.md`**。

## 1. 链路简述

1. 浏览器将当前大图写入 **本地伴侣** 项目 Volume（`PUT`）。
2. 伴侣提交计算任务 **`sam_segment`**，由 **`samSegmentAdapter`** 转发到 **SamLocal** `POST /v1/segment/predict`。
3. 分割结果为 PNG mask，写回 Volume；网站再 `GET` 该资产并显示为新版本。

**数据驻留**：默认仅在本机伴侣目录与 SamLocal 进程内处理，不经由产品云端分割 API。

**依赖版本**：`segment_anything` 由 **`SamLocal/requirements-sam.txt`** 固定为 Meta 官方仓库某一 **Git commit**（可复现）；升级上游时替换其中 **`@` 后哈希** 并重新 `pip install -r requirements-sam.txt` 后做本机分割回归。

## 2. 启动检查清单

设置页 **本地伴侣 → 本机分割（SamLocal）** 提供 **「复制环境变量示例」**，可将 `COMPANION_SAM_SEGMENT_URL` 与可选的 **`COMPANION_SPAWN_SAM_LOCAL_*`** 粘贴到运行伴侣的终端或系统环境变量（须把示例中的 `REPO_ROOT` 换成本机仓库根路径）。

**首次启用 `SAM_MODE=sam`**：在**克隆了本仓库的机器**上，于仓库根执行 **`npm run setup:sam-local`**（安装 `SamLocal/requirements.txt` + `requirements-sam.txt`，并下载 ViT-B 权重；耗时与网络有关，含 PyTorch 时可能较长）。企业/离线批量部署见 **`docs/本机分割一键安装指南.md`**。

| 步骤 | 说明 |
| --- | --- |
| 本地伴侣 | 桌面壳或 `local-companion` 已监听（默认 `http://127.0.0.1:18765`） |
| 网站配对 | 设置 → **本地伴侣** → 已保存通信密码且 **一键连接** 成功 |
| SamLocal | 仓库根目录执行 **`npm run dev:sam-local`**（或等价启动 FastAPI，默认端口 **18081**）；**一键联调**（由伴侣随启 SamLocal）：仓库根 **`npm run dev:companion-sam-stack`**（勿再单独开 `dev:sam-local`，以免占端口） |
| 伴侣环境变量 | 运行伴侣的进程中 **`COMPANION_SAM_SEGMENT_URL`** 指向完整 predict URL，默认 `http://127.0.0.1:18081/v1/segment/predict` |
| 伴侣自动拉起 SamLocal（可选） | 设置 **`COMPANION_SPAWN_SAM_LOCAL_CMD`**（shell 命令，如 `npm run dev:sam-local`）及可选 **`COMPANION_SPAWN_SAM_LOCAL_CWD`**（monorepo 根目录，便于 npm 解析脚本） |

## 3. 设置页自检

打开 **设置 → 本地伴侣**：

1. **重新检测**：确认健康检查与能力清单成功。
2. **探测 SamLocal（经伴侣）**：由伴侣请求 `GET /v1/debug/sam-segment-health`，转发探测 SamLocal 的 **`GET /health`**（避免浏览器跨端口 CORS）。
3. **复制环境变量示例**：与本节 **§2** 说明一致，便于配置伴侣进程环境。
4. 展开 **连接与能力详情 → 本机分割能力（samSegment）**：查看 `predictEndpoint`、环境变量名是否与你的本机一致。

## 4. 常见现象

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 日志提示本机分割服务未启动 | SamLocal 未起或端口错 | 启动 `npm run dev:sam-local`；检查 18081 |
| 503 / 模型未就绪 | `SAM_MODE=sam` 但缺 **`pip install -r requirements-sam.txt`**、缺权重或 torch 未装好 | 按 **`SamLocal/checkpoints/README.md`** 放置 ViT-B；或暂用 **`SAM_MODE=stub`** |
| `sam_missing_checkpoint`（`/health`） | 未找到 `SAM_CHECKPOINT_PATH` 或默认路径下无 `.pth` | 下载 ViT-B 检查点到 `SamLocal/checkpoints/` |
| 选区与图片尺寸不匹配 | 大图自然尺寸与 prompt 不一致 | 关闭大图重新打开再试 |
| 写入伴侣失败 | 伴侣未连接或未选工作区项目 | 先选项目；检查配对与 Base URL |
| 探测接口提示非回环地址 | `COMPANION_SAM_SEGMENT_URL` 指向了外网或非 127.0.0.1 | 规格要求 Sam 后端须为 **本机回环**（防 SSRF） |
