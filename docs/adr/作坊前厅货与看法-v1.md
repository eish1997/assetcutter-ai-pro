# ADR：作坊前厅货与看法 v1.2

**状态**：已采纳（2026-09-18 v1；同日修订 v1.1；2026-09-19 修订 v1.2）  
**决策者**：架构评审（前厅分层）  
**关联**：`docs/架构宪章-本地壳大楼租户.md` §3.1 / §3.12、`docs/架构未收口清单.md` C3、`services/workshopFrontHall.ts`

## 背景

作坊前厅要对标 Connecter 的库，再加上可看、可生成的无限画板。v1 钉死「不要另造一份资产表」。v1.1 改掉「网格和画板 ID 必须相等」：同源是**挂上的那一个根**，两种看法的集合不同构。v1.2 把种类/名称筛选接到画板**显示**，仍不改 L0，也不改已保存的坐标。

产品位置不变：不是下一个 Cursor。Figma / Lovart / 飞书白板只借无限画布、相机和框，不借它们的文件模型。

## 决策

| 议题 | 结论 |
|------|------|
| 货（L0） | 本机文件。资产列表只显示**左树当前夹**里磁盘上的文件（`listCanvas` 当前层）。 |
| 画布范围 | 「+」挂上的**那一个根 = 一张画布**。再挂一个根 = 另一张画布。 |
| 框 | 子文件夹是画板上的框。**框内 = 文件夹内**。掏空后**空框仍在**（状态里）。 |
| 相机 | 左树点进子文件夹 = 相机飞到该框，不换画布。同一挂根下的相机与节点坐标下次打开仍在。 |
| 画板集合 | 该根下全部节点：本地文件的版本/步骤 + 该夹 `folder_index` 的画布节点，用框表达层级。 |
| 列表筛选 | 种类筛选、名称筛选**同时改列表和画板显示**。不拆框、不改归属、不改 persist 坐标。没有可见子节点的框可以不画。摊平仍只改列表。 |
| 本地标识 | 可拖动的「本地文件槽」。默认本地文件带着标识。一节点可挂多枚。 |
| F3 | 增删槽：新建源文件进当前框对应文件夹，或回收该槽对应文件。不覆盖已有槽。 |
| 拖标识 | 该槽字节换成目标节点内容，标识改挂到目标；文件归属变成目标节点所在框的文件夹。 |
| 手指 | 画布当前**选中节点**。无选中则空。无标识则无磁盘路径。 |
| 性能 | 身份可铺满整根；屏外不 hydrate。只借开源无限画布的视口策略，快照不当 L0。 |
| 种类（L4） | 插件只登记怎么画，不拥有文件字节。 |
| 本轮界面 | 网格/画板已挂 vendor InfiniteCanvas。契约见 `services/workshopFrontHall.ts`。 |

v1 硬约束「grid 与 board 的 id 集合必须相等」**作废**。

## 分层

```text
挂上的根 = 一张画布
  子文件夹 = 框（空框保留在状态里）
  框内节点 = 该夹的版本节点 + folder_index 画布节点
左树当前夹 = 相机看哪个框
资产列表 = 当前夹的 L0 文件（可筛选）
画板显示 = 同一套种类/名称筛选，只藏节点，不改货
本地标识 = 可拖的文件槽（可叠在同一节点）
选中节点 = 手指
```

## 硬约束

1. `grid.ids` 等于**当前夹** listing 的文件身份，不是整张画板。
2. 画板可以比当前 listing 多（其它框里的节点、未落地版本、folder_index、空框）。
3. 带本地标识的文件路径必须落在该标识所挂节点所在框的文件夹里。
4. 当前夹 listing 被掏空后，该夹对应的框仍在 board 的 frames 集合里。
5. 对 listing 做种类筛选 / 摊平，board 的节点 id 与 frames **状态集合不变**；种类/名称筛选只改画板**看见谁**。
6. F3 增加槽：listing 多一条；F3 去掉槽：listing 少一条，**同一节点仍在 board**。
7. 布局丢失不删 listing，也不删 frames / folder_index 节点（只丢坐标）。已保存的坐标下次打开必须还在，禁止每次按默认网格重排。
8. Kind 登记不能声明拥有文件字节。
9. 禁止 persist `localhost` / `127.0.0.1` / `::1`。画板预览可以用会话内 `data:` / `blob:`，不得把本机地址写成货。
10. 不引入 tldraw / excalidraw 作为货仓；视口库只能做 culling / 相机。
11. 库级画板不画 Comfy 连线执行。

## 理由

1. **范围同源、集合不同构**：列表是当前夹的货架；画板是整根的空间样子。用 ID 相等当公理会把步骤和空框从画板上抹掉。
2. **框即夹**：空间可写就必须有归属，否则框是撒谎的装饰。
3. **标识是槽**：F3 管「有没有这份本地文件」；拖标识管「这份文件现在等于哪个版本」。叠标识 = 多份本地文件当前都是这一版。
4. **手指跟镜头里的选择**：管家和送出认选中节点；没有标识就不能假装有路径。
5. **筛选是看法**：藏起来不等于删货；用户要在画板上也只看当前种类/名字。

## 后果

- 实现以 v1.2 为准；v1 测试里「两投影 ID 相等」不再是正确公理。
- 灯箱步骤树是画板节点在聚焦前的现有皮肤；列表仍然不展开步骤。
- 技能 / 工具 / 地图 / dsh 循环仍不动。

## 替代方案（未采纳）

| 方案 | 未采纳原因 |
|------|------------|
| 画板文件当真源 | 文件夹不再是货 |
| 每一层目录一张独立画布 | 和「子夹是框、左树是相机」冲突 |
| 掏空后拆掉空框 | 画布节点与文件夹层级会丢 |
| 筛选改写 board 状态 / persist | 用户会以为货被删了；隐藏节点的坐标会丢 |
| 用 tldraw 快照当货仓 | 第二份真源 |
| 库画板做成 ComfyUI 执行图 | 种类插件被做成运算节点 |
