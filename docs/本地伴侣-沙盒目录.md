# 本地伴侣 · Windows 沙盒目录（清单）

**根路径（默认）**：`%LOCALAPPDATA%\AssetCutterCompanion\sandbox\`

未公开发布前可整树删除该目录以清空本机引擎、缓存与（默认）卷数据；桌面壳设置、配对等位于 `sandbox\desktop-shell\`。

首次启动时：若存在旧版 **`%LOCALAPPDATA%\AssetCutterCompanion\desktop-shell`** 或 **`...\runtimes`**，且沙盒内对应路径尚不存在，则**整目录重命名迁入**沙盒（无需用户查找旧路径）。`%USERPROFILE%\.assetcutter-companion\volume` 不在自动迁入范围内；未指定存储路径时默认使用 **`sandbox\volume`**（空则随项目写入自动增长）。

## 目录清单

| 相对路径 | 用途 |
|----------|------|
| `desktop-shell\` | Electron `userData`：设置、配对、`sam-local-runtime` / `rembg-runtime` 薄状态、`local-companion-spawn.log` 等 |
| `runtimes\<runtimeId>\<version>\` | 嵌入 Python、`pip` 安装的 PyTorch / rembg 等大依赖、`_cache`、运行时 `manifest.json` |
| `models\rembg\` | rembg 下载的 onnx 权重（`U2NET_HOME`，由伴侣子进程与一键安装脚本共用） |
| `cache\pip\` | `PIP_CACHE_DIR`，一键安装与 pip 复用 |
| `cache\torch\` | `TORCH_HOME`，SamLocal 启动脚本注入 |
| `cache\huggingface\` | `HF_HOME`，供 PyTorch/HF 生态缓存（预留） |
| `volume\` | **默认**本机卷根：未在桌面壳「存储」中指定 `COMPANION_VOLUME_ROOT` 时，由 `local-companion` 使用（`COMPANION_SANDBOX_ROOT` + `/volume`） |

## 环境变量（由桌面壳注入子进程）

| 变量 | 说明 |
|------|------|
| `COMPANION_SANDBOX_ROOT` | 沙盒根；`local-companion` 据此默认卷路径与 rembg `U2NET_HOME` |
| `AC_COMPANION_SANDBOX_ROOT` | 同上；一键安装子进程（`sam-local-bootstrap` / `rembg-bootstrap`）**必填** |
| `COMPANION_REMBG_MODELS_DIR` | 可选；显式覆盖 rembg 模型目录（否则为 `<沙盒>/models/rembg`） |

## 实现入口

- 路径常量：`companion-desktop/companion-sandbox-paths.cjs`
- Electron `userData` 与伴侣 spawn：`companion-desktop/main.cjs`
- 一键安装：`companion-desktop/sam-local-bootstrap/sam-local-bootstrap.cjs`、`companion-desktop/rembg-bootstrap/rembg-bootstrap.cjs`
- 伴侣默认卷与 rembg 子进程：`local-companion/src/repositoryVolume.ts`、`local-companion/src/compute/rembgAdapter.ts`
