# 线上生图部署清单

> **背景**：本地 `npm run dev` 经 Vite 同源反代 `/api/*`，浏览器不跨域；Vercel / 公网静态站无此反代，须浏览器跨域访问 `*.onrender.com` 并带积分 Cookie。  
> **触发**：7525000 积分闸门后，生图链路 = 登录 Cookie + `credits-proxy-bundle` + auth 中继 `/api/gemini-proxy/*`。  
> **原则**：后端脚本 E2E 通过 ≠ 浏览器路径通过；以浏览器 Network 为准。

## F. 故障对照（快速定位）

| 现象 | 优先查 |
|------|--------|
| `Vertex 生图服务暂时连不上` / `fetch failed` | Network 是否跨域到 auth-api；B2 中继 healthz；CORS 预检 204 |
| `积分预扣无效或已过期` | 前端是否 `9a173bf+`；重新登录后再试 |
| `积分不足`（余额实际很多） | 孤儿预扣：B2 `credits-release` CSRF；清 pending；等 ~15min TTL |
| 本地通、线上不通 | **正常**：本地 Vite 反代 ≠ 线上跨域；完成 B+C+E |
