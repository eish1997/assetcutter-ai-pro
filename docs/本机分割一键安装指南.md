# 本机分割（SamLocal）一键安装指南

面向 **有本仓库源码** 的开发机或 **由 IT 分发同一目录树** 的内网环境。视频与 SAM 2 不在本文范围。

## Windows 桌面壳（无需终端）

若使用 **AssetCutter 桌面应用（Windows）** 且安装包已携带内置 **SamLocal 资源**（构建时 `extraResources/sam-local-bundled`）：

1. 打开桌面壳 → **设置** → **本机分割（SamLocal）**
2. 点击 **一键安装高精度引擎**，在日志区等待完成（首次会下载嵌入式 Python 与 ViT-B 权重，可能较久，请保持网络畅通）
3. 成功后壳会尝试 **重启本地伴侣**，并由主进程注入 **`COMPANION_SPAWN_SAM_LOCAL_*`**，伴侣随启 SamLocal

若界面提示当前构建**未包含 SamLocal 资源**，请换用完整桌面发行包（打包前在仓库根执行 `npm run copy:sam-local-bundled --prefix companion-desktop`），或继续按下文 §2 在克隆仓库中用终端执行 `npm run setup:sam-local`。

## 1. 前置条件

- **Node.js**（与项目一致，建议 Current LTS）— 用于执行 `npm run setup:sam-local`
- **Python 3.10+** 与 **pip**，且在 PATH 中（Windows 常见为 `python` 或 **`py -3`**）
- 可访问 **PyPI** 与 Meta 权重 CDN；完全离线环境请改用镜像与人工拷贝权重（见 §4）

## 2. 推荐路径（单命令）

在**仓库根目录**执行：

```bash
npm run setup:sam-local
```

脚本会依次：

1. 在 `SamLocal/` 下执行 `pip install -r requirements.txt -r requirements-sam.txt`（可能较久）
2. 将 **`sam_vit_b_01ec64.pth`** 下载到 `SamLocal/checkpoints/`（约 375MB）

可选参数：

- **`--skip-pip`**：仅下载权重（依赖已装好时使用）
- **`--skip-download`**：仅 pip（已有权重时使用）

仅补权重：

```bash
npm run download:sam-vit-b
```

强制重新下载权重（覆盖损坏或不完整文件）：

```bash
npm run download:sam-vit-b -- --force
```

## 3. 验证

1. 设置环境变量 **`SAM_MODE=sam`**（或在 `SamLocal/.env` 中配置，视你方启动方式而定）
2. 仓库根：`npm run dev:sam-local`
3. 浏览器或 `curl` 访问 `http://127.0.0.1:18081/health`，确认模型状态非 `sam_missing_checkpoint`

与伴侣联调：见 **`docs/本机分割故障排除.md`** 与 **`docs/本地伴侣SAM分割-产品开发规格.md`**。

## 4. 企业 / 离线场景

- **无 PyPI**：在一台有网络的构建机上完成 `setup:sam-local`，将整个 `SamLocal/`（含 venv 若使用）或 wheel 缓存打包到内网；或在内网配置 **pip 镜像** 后重跑 `npm run setup:sam-local -- --skip-download` 仅装依赖，再人工拷贝 `.pth` 到 `SamLocal/checkpoints/`。
- **无仓库仅安装包**：Windows 完整桌面包可走上一节 **一键安装**；其余平台仍以 **环境变量 + 用户自备 Python** 为主；宿主 **`host_plugin_bundle`** 的 **`exec`** 不用于常驻 HTTP，详见 **`docs/本地伴侣-插件与发行.md`**。

## 5. 相关命令速查

| 命令 | 作用 |
| --- | --- |
| `npm run setup:sam-local` | pip + 下载 ViT-B |
| `npm run download:sam-vit-b` | 仅下载权重 |
| `npm run dev:sam-local` | 启动 SamLocal HTTP |
| `npm run dev:companion-sam-stack` | 伴侣 + 随启 SamLocal（开发一键栈） |
