### 2026-07-08: 线上变体/线稿生图 `fetch failed`（7525000 积分闸门 + CORS）
- 现象：`app.adrazzo.com` 工作区「变体」等生图报 `[变体] fetch failed`（全局日志 `[WARN] [工作区] [变体] fetch failed`）
- 原因：**7525000** 起 `bulkFetchOrExplain` 带 `credentials:include`（积分 Cookie）；浏览器跨域直连 `assetcutter-gemini-proxy.onrender.com` 触发 CORS 预检；**线上 proxy 对 `Origin: https://app.adrazzo.com` 返回 403 `Origin not allowed`**（`assetcutter-web.onrender.com` 在白名单内可 204）。bd2e257 仅补 `Allow-Credentials`，**未合并 BUILTIN 域名**；auth-api `/api/gemini-proxy/*` 中继尚未部署（404）
- 修复：① `gemini-proxy-api.js` 合并 `BUILTIN_PROXY_ALLOWED_ORIGINS`；② auth-api 中继 + **`Allow-Headers` 含积分/公平性头**；③ **`GEMINI_PROXY_*` 未设时生产默认 Render 上游**（勿连 127.0.0.1:9002）；④ Vercel 无 `VITE_AUTH_API_BASE_URL` 时直连 gemini-proxy（勿走相对 `/api/gemini-proxy`）
- 涉及：`server/gemini-proxy-api.js` `gemini-proxy-relay.js` `auth-api.js` `services/geminiService.ts` `render.yaml`；**须 redeploy gemini-proxy + auth-api + 前端静态站**
