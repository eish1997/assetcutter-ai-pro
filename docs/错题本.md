# 错题本

记录开发与使用中出现的问题及修复方式，便于复现与排查。

## 使用说明

- **何时记**：报错、崩溃、逻辑与预期不符、线上/本地踩坑等。
- **怎么写**：现象 → 原因（若已知）→ 修复或规避 → 涉及文件/提交（可选）。
- 按时间**倒序**追加（最新在上），或统一用二级标题按日期分块。

## 2026-04

### 浏览器标签页 Out of Memory（全景 / 大图）

- **现象**：Chrome 提示「喔唷，崩溃啦」错误代码 Out of Memory；Network 里大量图片与 base64。
- **原因**：全景用 `TextureLoader` 将原图整分辨率上传 GPU，叠加 mipmap；工作流中常见超大图或 `data:image/...;base64`，解码 + 显存暴涨。
- **修复**：`EquirectangularPanoramaCanvas` 中先 `Image` 解码，按最长边 **cap 到 4096** 画到 canvas 再 `CanvasTexture`；边长 >2048 关闭 mipmap；渲染器 `antialias: false`、`pixelRatio` 上限 1.5。
- **涉及**：`components/EquirectangularPanoramaCanvas.tsx`

### 全景预览时 React removeChild / NotFoundError

- **现象**：切换到全景后控制台报 `Failed to execute 'removeChild' on 'Node'`。
- **原因**：`useEffect` 对**含 React 子节点**的容器执行 `innerHTML = ''`，删掉加载/错误覆盖层 DOM，与 React 协调不一致。
- **修复**：外层 `rootRef` 仅布局；内层 `mountRef` **只挂 WebGL canvas**，React 不在此节点插入其它子节点；加载/错误提示与 `mount` **平级**且更高 `z-index`。
- **涉及**：`components/EquirectangularPanoramaCanvas.tsx`

### ImagePreviewOverlay ESLint react-hooks/refs

- **现象**：`onCloseRef.current = onClose` 写在 render 中触发 lint。
- **修复**：改为 `useEffect(() => { onCloseRef.current = onClose }, [onClose])`。
- **涉及**：`components/ImagePreviewOverlay.tsx`
