# 项目交接文档（assetcutter-ai-pro）

本文面向后续开发者与 AI 助手：**快速理解仓库、关键模块、约定与扩展方式**。与具体需求无关的细枝末节以代码与 `.cursor/rules` 为准。

## 1. 项目概览

- **技术栈**：React 19 + TypeScript + Vite 6；部分能力使用 **Three.js**（全景、3D 预览等）。
- **仓库路径**：`assetcutter-ai-pro`（私有）。
- **运行**：`npm run dev`（Vite）；多服务见 `package.json`（`dev:all`、`dev:with-r2` 等）。

## 3. 重要约定（必读规则摘要）

- **下拉 UI**：禁用原生 `<select>`，用自定义 Portal 下拉（见 `CapabilityPresetSection` / `dropdown-ui-style` rule）。
- **跨设备 URL**：持久化数据勿写死 `localhost`；站内 API 路径在不同端口需改写为当前 `origin`（见 `cross-device-availability` rule）。
- **客户端持久化范式**：`localStorage` / `sessionStorage` 的新增读写优先走 `services/clientPersist.ts`（safe 包装、JSON/开关、按账号 `scopedStorageKey`）；工作区/项目/对话仍用专用 store（`workspaceProjectStore`、云同步、`dialogSessionStore` 等）。详见 `.cursor/rules/client-persist.mdc`。
- **工作流卡片预览**：`WorkflowGridImage` / `ProgressivePreviewImage` 父级须有确定高度 + `aspectRatio` 等（见 `workflow-asset-cards` rule）。
- **示例项目**：`示例项目/` 仅作参考，**禁止**在产品代码中 import 或依赖该目录工程。

## 4. 预览功能架构（扩展指引）

- **壳层**：`PreviewShell` — 遮罩、Esc、焦点、`focusKey` 切资产时 refocus。
- **注册表**：`getLazyImagePreviewViewer` / `registerImagePreviewLoader` — 按 `mode` 懒加载 Viewer（全景为 `image.equirect`）。
- **新增预览类型**：新增 `viewers/*.tsx` → 注册 mode → 扩展 `preview/types.ts`；重包体能力务必 **lazy**，并在 `previewPolicyForMode` 中声明是否占用全局滚轮等。
- **3D**：`UnifiedModelViewer3D` / `ModelViewer3D` 与工作流大图入口不同，长期可并入同一预览抽象。

## 5. 环境与构建

- 环境变量示例：`.env.example`；本地敏感配置：`.env.local`（勿提交）。
- 质量检查：`npm run typecheck`、`npm run lint`、`npm run test`、`npm run build`。
- **静态前端双托管（可选）**：同一仓库可同时接 **Vercel** 与 **Cloudflare Pages**。构建均为 `npm run build`，输出目录 **`dist`**。Vercel 使用根目录 `vercel.json` 做 SPA 回退；Pages 使用构建产物中的 **`_redirects`**（源文件 `public/_redirects`，由 Vite 复制到 `dist`）。两边需在控制台分别配置相同的生产用 `VITE_*` 变量；Render 上 `AUTH_ALLOWED_ORIGINS` 须包含两个前端的 Origin（及未来自定义域名）。

## 6. 后续开发注意

- **大文件**：`WorkflowSection.tsx` 修改前先局部搜索，避免重复逻辑；能抽 hooks/子组件时优先降低单文件体积。
- **内存**：工作流中减少超长 base64 常驻；全景已做纹理 cap，新增 WebGL 能力需考虑 **dispose** 与 **并发预览数**。
- **文档**：会话交接与错题按项目 skill `session-handoff-log` 维护 `docs/错题本.md` 与本文件。
