# 分镜表 P0 清单

**目标**：在工作区增加「分镜表」容器资产，点开是有设计感的行列表格；支持手填/手改行数据。

**边界（P0 不做）**

- 不用组资产 + 子图卡承载行
- 不用文字卡一行一张
- 不做：文本拆分 → 生图 → 切图预设
- 不做：批量 feedback 重绘、按秒数合成条带图
- 不做：侧栏「分镜流程」全自动（可只留「新建空表」占位）

---

## 一、数据与资产类型

| # | 项 | 说明 |
|---|-----|------|
| 1 | 新容器类型 | `assetKind: 'storyboard_table'`，与工作区图卡/文字卡/组区分 |
| 2 | 行数据内嵌 | 父资产上 `storyboardTable.rows[]`，每行独立 `id` |
| 3 | 行字段 | `index`、`shotNo`、`durationSec`（可空）、`shotText`、`frameImage`（可空）、`related`（可空）、`locked`（默认 false） |
| 4 | 存图方式 | 与现有项目一致：能 hydrate、跨设备 |
| 5 | 网格展示 | 主工作区只显示 1 张表卡 |
| 6 | 持久化 | 随工作区 bundle 保存/同步 |

---

## 二、入口与导航

| # | 项 | 说明 |
|---|-----|------|
| 7 | 新建 | 工作区「新建分镜表」，默认 1～3 空行 |
| 8 | 打开 | 点击表卡 → 大面板分镜表 |
| 9 | 关闭 | 面板关闭回网格；表卡显示行数/标题摘要 |
| 10 | 视觉区分 | 表卡图标/角标与图卡、组卡不同 |

---

## 六、验收标准

1. 能新建分镜表，工作区只见一张表卡。
2. 打开后可增删改行、改镜头号/秒数/文本、上传或替换行图。
3. 锁定可切换并保存，刷新/重开项目仍在。
4. 与组、文字卡无共用「一行一子资产」结构。
5. 样式区别于 Excel 灰表（字左图右、hover/当前行/空图态）。

---

## 七、后续阶段

| 阶段 | 内容 |
|------|------|
| P1 | 单行「重绘」→ 文生图/图生图写回 `frameImage`（**已实现**） |
| P2 | 批量 feedback + 跳过锁定行 |
| P3 | 按 `durationSec` 合成约 15 秒条带图 |
| P4 | 预设流水线：整集文本 → 拆分 → 生图 → 切图 → 灌表 |

## 八、实现模块

- `components/storyboard/storyboardFrameImage.ts`：读图 + JPEG 压缩（约 2MB 内）
- `components/storyboard/StoryboardTablePanel.tsx`：全屏三栏（大纲 / 编辑 / 合成）
- `components/storyboard/StoryboardTableOutlineSidebar.tsx`：左栏大纲，点击滚动定位
- `components/storyboard/StoryboardTableCompositeColumn.tsx` + `StoryboardFrameCompositeCard.tsx`：右栏图文合成卡
- `components/storyboard/StoryboardTableRowEditor.tsx`：单行编辑器
- `components/storyboard/StoryboardTableGridCard.tsx`：工作区表卡（胶片条预览）
- `WorkflowSection.tsx`：新建入口、渲染分支
- bundle sanitize / hydrate
- `tests/storyboardTableAsset.test.ts`

## 九、P1 重绘

- 表头 **重绘能力** 下拉：可选已启用的文生图 / 图生图预设（记忆上次选择）
- 每行 **重绘** 按钮：用镜头文本（+ 镜头号）调用 `executeCapability`，结果压缩后写回 `frameImage`
- **锁定** 行不可重绘；**图生图** 需本镜已有分镜图；**文生图** 仅需镜头文本
- 实现：`services/storyboardTableRedraw.ts`

## 十、产品级交互（P0+）

- 表头统计：镜数 / 配图数 / 累计秒数（未填齐时标注）
- 工具栏：添加镜头、自动镜头号、复制当前镜
- 行内：字左图右、拖入/粘贴配图、替换/清除、锁定
- Esc 关闭；打开时锁定 body 滚动
- 配图自动压缩，避免撑爆工作区 JSON
