## Goal

挂上的**一个作坊根**可切到无限画板：CSS 世界坐标平移/缩放；子文件夹是框（空框保留）；左树 `rel` 把相机飞到该框；画板选中节点即手指；F3 增删本地槽；拖标识把该槽字节换成目标节点并改归属。列表的摊平/种类筛选仍只作用于网格，不改 board 集合。

一句话：本计划交付 **可平移缩放的挂根画板 + 标识/F3**，不是 Figma 皮肤，也不是把灯箱收成画布聚焦。

## Non-goals

- 不引入 tldraw / excalidraw / pixi / 任何新 npm 画布库（相机用自研矩阵 + CSS `transform`）。
- 不把 tldraw/excalidraw 快照当 L0；布局只进 L1。
- 不把灯箱改成「画布相机聚焦」；`AssetPreviewOverlay` 可继续盖层打开。
- 不升级 `WORKSHOP_PREVIEW_KIND_DEFS` 为 L4 注册表，不收 C1。
- 不在库画板上画 Comfy 连线执行。
- 不拆 `WorkflowSection.tsx` 整文件；不改技能 / 工具 / 地图 / dsh。
- 不把列表 `flatten` / 种类筛选作用到 board 集合。
- 不做 folder_index **新建编辑器**（只读已有 JSON）。
- 不做 Figma 级视觉打磨；禁止 HAND_GATE / 截图验收。
- 不宣称未收口 C3 全部闭环（灯箱、种类插件仍 open）。
- 能力预览 / `canvasExportImage` 等无关 WIP 禁止混进 Modify。

## Already decided（禁止任务里重开）

1. 挂根一张画布；子夹是框；框内=夹内；空框保留。
2. 列表只显示当前夹本地文件；筛选/摊平不动画板。
3. 默认每个本地文件带着一枚本地标识；一节点可挂多枚。
4. 画板选中节点才是手指；无标识则无路径。
5. 屏外不 hydrate：身份可铺满，字节只给 `visibleNodeIds`。
6. 货仍是文件夹；布局丢失只丢坐标，不丢文件/空框/folder_index 节点。
7. **引擎**：`services/workshopFrontHallCamera.ts` + 一层 `data-front-hall-world` 的 CSS translate/scale。禁止加画布 npm 依赖。
8. **F3**：无修饰键 = 给选中节点（若无选中则当前相机框）新建源文件并挂一枚新标识；`Shift+F3` = 回收选中节点上最后一枚标识对应文件。磁盘走已有 `createCheckoutFile` / `trashEntries`，不新开 IPC 品牌。
9. **拖标识**：状态用已有 `dragTokenToNode`；字节用已有 `applyCheckout`（目标节点若是文件节点，源为该节点 `rel`）；文件物理归属改到目标框文件夹（`renameEntry` 或等价）。
10. 灯箱步骤树本阶段仍可打开；包资产额外节点仅由 `ac-asset.json` 的 `files` **投影**到画板，不重写灯箱。
11. `listCanvas(includeSubfolders)` 仍是列表摊平，**不**改成画板树；画板另用 `listBoardEntries`。

## Agent loop protocol

1. Observe：本文件「当前进度」+ 该任务 Inputs。
2. Select：第一个 `pending` 且 Depends 皆 `done`。
3. Act：只改 Modify 列表。能抽纯函数就抽。
4. Verify：只跑该任务 Automatic verification。改了 `companion-desktop/` 运行时则后台重启伴侣，然后仍用 vitest 判定。
5. Record：追加证据；Status=done；更新当前进度。
6. Continue。停机：全部 done / blocked / LIVE_GATE。

HAND_GATE: none。LIVE_GATE: none。缺本机伴侣时：P7/P12/P13 仍用 `workshop-file-tree.cjs` 的 vitest 夹具（不连 Electron），Remaining risk 可记 `live_host_unverified` 并继续。同失败 3 次 → blocked。

禁止重开 ADR v1.1。扩大 Modify 必须先改本文件。
