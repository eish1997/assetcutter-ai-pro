# 分镜表 · 结构化解析优化方案

**目标**：用「结构化解析预设」（文生文能力）把镜头输入文本自动拆成动态字段；后续 AI 优化、重绘、大纲均基于字段而非单一 `shotText` 大框，避免润色时丢失景别、对白、机位等格式。

**状态**：v0.3（S1–S6 已实现；S7 整集灌表待做）。

**关联文档**：[`docs/分镜表-P0.md`](./分镜表-P0.md)（容器与面板基础）、[`docs/交接文档.md`](./交接文档.md)。

## 二、边界（本阶段不做）

- 用户手搓任意列名（无「字段管理」UI；列仅由解析结果生长）
- 固定 7 列 schema 强制全覆盖
- 图片/数字/下拉类动态字段（v1 仅文本 / 多行文本）
- CSV / Excel 整表导入导出
- 跨工作区「字段模板库」同步（可后续 P2）
- catalog 列隐藏 / 删除 / 合并 UI（v1 catalog 只增不减）
- 整集文本 → 拆分 → 灌表全自动流水线（见 §十 S7，本 spec 只定义解析内核）
- **不保证**用户任意改写预设 `instruction` 后仍能稳定 JSON 解析（契约由代码校验，失败 toast）

## 三、核心概念

```
shotRaw（用户输入 / 粘贴原文）
        ↓  parseStoryboardTextWithPreset（文生文 · JSON）
ParseResult.fields[]  { label, value, kind?, redrawInclude? }
        ↓  mergeFieldCatalog + applyShotFieldsPatch
fieldCatalog（表级动态列目录） + shotFields（行级值）
        ↓  compileShotText（normalize 时亦强制）
shotText（派生只读，供视频时间轴 / 旧消费方）
        ↓  compileRedrawPrompt（重绘专用）
重绘 prompt（redrawInclude 字段子集）
```

| 概念 | 层级 | 职责 |
|------|------|------|
| `shotNo` / `durationSec` | 行 · 系统固定 | 镜头号、时长；手填，解析不改 |
| `shotRaw` | 行 | 解析前原文；解析成功后更新为本次输入快照 |
| `fieldCatalog` | 表 | 本表出现过的动态字段目录（列定义） |
| `shotFields` | 行 | `Record<fieldId, string>` 结构化真源 |
| `shotText` | 行 · 派生 | `compileShotText` 生成；**禁止**作为编辑主入口或直接解析输入 |
| `parsePresetId` | 表 | 本表选用的解析预设 id（云同步真源） |

## 四、数据模型

### 4.1 类型（`types.ts`）

```ts
/** 动态字段目录项（表级，解析结果并集） */
export type StoryboardParseFieldDef = {
  /** 稳定键，由 label 规范化生成，创建后不变 */
  id: string;
  /** 展示名，如「画面」「对白」「音效」 */
  label: string;
  /** UI 排序，越小越靠前 */
  order: number;
  /** 入 catalog 时推断并持久化；之后不随 label 文案重算 */
  redrawInclude: boolean;
  kind: 'text' | 'multiline';
};

export type StoryboardTableDoc = {
  title?: string;
  timelineLayerCount?: number;
  rows: StoryboardTableRow[];
  /** 动态字段目录（全表并集）；新表默认 [] */
  fieldCatalog: StoryboardParseFieldDef[];
  /** 结构化解析预设 id（表级真源） */
  parsePresetId?: string;
  /** 结构化优化预设 id（S6，可选） */
  optimizePresetId?: string;
};

export type StoryboardTableRow = {
  id: string;
  index: number;
  shotNo?: string;
  durationSec?: number | null;
  /** 解析前原文；解析后保留快照 */
  shotRaw?: string;
  /** 结构化真源；新行默认 {} */
  shotFields: Record<string, string>;
  /** 派生：仅由 compileShotText 写入 */
  shotText: string;
  frameImage?: string;
  frameImageObjectKey?: string;
  frameImageCompanionKey?: string;
  locked?: boolean;
  timelineLayer?: number;
};
```

**破坏性变更**：

- 删除「`shotText` 为唯一文本真源」的假设
- `normalizeStoryboardTableDoc` 最后一律对每个 row 执行 `shotText = compileShotText(catalog, shotFields)`
- 加载旧 bundle 若仅有 `shotText`、无 `shotFields`：normalize 时将 `shotText` 迁入 `shotRaw` 并清空 `shotFields`（**不**自动调用 LLM；用户手动点解析）

### 4.2 字段 id 生成

```ts
// services/storyboardTableParse.ts
slugifyFieldLabel(label: string): string
// 1. trim → 小写 → 非 [a-z0-9\u4e00-\u9fff] 替为 _
// 2. 前缀 f_ 避免与系统键冲突
// 3. catalog 内按 label 精确匹配（trim 后）复用已有 id
// 4. 新 label → 新 id；slug 冲突 → f_xxx_2, f_xxx_3
```

同表内 **同 label 复用同 id**；不同 label（「台词」vs「对白」）在 v1 视为不同列，靠预设 instruction 约束命名一致。

### 4.3 fieldCatalog 合并算法

输入：当前 `fieldCatalog`、本镜解析结果 `fields[]`、本行现有 `shotFields`

```
nextFields = { ...row.shotFields }

for each parsed field（按返回顺序）:
  id = resolveFieldId(catalog, label)   // 已有 label 匹配则用原 id
  if catalog 中无 id:
    append { id, label, order: max+1, kind, redrawInclude }
  else:
    可选更新 catalog[id].label = label   // 展示名以最近一次解析为准
  nextFields[id] = value

// 未出现在本次解析结果中的 id：保留 nextFields[id] 原值（D11）

row = applyShotFieldsPatch(row, catalog, nextFields)
```

**`redrawInclude` 默认值**（仅在**新建 catalog 项**时推断一次并写入）：

| 条件 | `redrawInclude` |
|------|-----------------|
| label 匹配 `/对白\|台词\|音效\|备注\|音乐\|旁白/` | `false` |
| 模型 JSON 显式提供 `redrawInclude` | 以模型为准 |
| 其余 | `true` |

### 4.4 编译与补丁（单一写入口）

```ts
compileShotText(catalog, fields): string
// 按 catalog.order；跳过空值；格式 【{label}】{value}；行间 \n

compileRedrawPrompt(row, catalog, promptExtra?): string
// 1. 【镜头号 {shotNo}】（若有）
// 2. redrawInclude===true 且非空的字段，按 order：【{label}】{value}
// 3. promptExtra

applyShotFieldsPatch(row, catalog, nextFields): StoryboardTableRow
// shotFields = nextFields；shotText = compileShotText(catalog, nextFields)；返回 row

pickPrimaryVisualField(catalog, fields): { id, label, value } | null
// 1. label 匹配 /画面|镜头|视觉|prompt/i 且非空
// 2. 否则 redrawInclude===true 且 order 最小的非空字段
// 大纲副文案、合成卡正文、视频 footer 均走此函数，不走整段 shotText
```

## 五、解析预设与执行

### 5.1 预设筛选与存储

```ts
listStoryboardParsePresets(presets: CustomAppModule[]): CustomAppModule[]
// category === 'text_to_text' && !disabled
// 推荐：id.startsWith('storyboard_parse_')
```

| 存储 | 键 | 用途 |
|------|-----|------|
| 表级真源 | `storyboardTable.parsePresetId` | 随 bundle 云同步；打开面板时用于下拉默认值 |
| 设备默认 | `ac_storyboard_parse_preset_v1` | **仅**新建分镜表时写入 `parsePresetId` 的初始值 |

对齐重绘：重绘仍用设备级 `ac_storyboard_redraw_preset_v1`；解析因需跨设备一致，以表级为准。

### 5.2 种子预设（固定落点）

**并入** `public/capability-seed/capability-presets.json` 一条（不单独文件）：

| 属性 | 值 |
|------|-----|
| `id` | `storyboard_parse_structured_v1` |
| `label` | 分镜结构化解析 |
| `category` | `text_to_text` |
| `engine` | `gen_text` |

### 5.3 预设 instruction（种子正文）

```text
你是分镜脚本结构化助手。根据用户输入的分镜文本，拆成若干语义字段。

要求：
1. 字段名（label）由你根据内容自行决定，例如：画面、对白、景别、机位、动作、音效、备注等。
2. 没有信息的维度不要编造，不要输出空字段。
3. 同一语义全程使用相同 label（例如始终用「对白」，不要有时写「台词」）。
4. 保留原文措辞，不要擅自翻译或合并不同维度。
5. 镜头号、时长若出现在原文中，可解析为对应 label，但不要编造。
6. 对「画面」「动作」「景别」「机位」类字段设 redrawInclude: true；对「对白」「音效」「备注」类设 false。

只输出 JSON，不要 markdown 代码块：
{
  "fields": [
    { "label": "景别", "value": "中景", "redrawInclude": true },
    { "label": "画面", "value": "…", "redrawInclude": true, "kind": "multiline" },
    { "label": "对白", "value": "…", "redrawInclude": false }
  ]
}
```

### 5.4 模型输出契约

```ts
type StoryboardParseModelOutput = {
  fields: Array<{
    label: string;
    value: string;
    kind?: 'text' | 'multiline';
    redrawInclude?: boolean;
  }>;
};
```

归一化：

- `fields` 必须为数组；否则抛错
- `label` / `value` trim；空 label 或空 value 丢弃
- 单项 value 上限：text 500 字，multiline 4000 字
- 单次解析最多 16 个字段

### 5.5 专用解析执行（非通用 executeCapability）

```ts
parseStoryboardTextWithPreset(
  input: string,
  preset: CustomAppModule,
  ctx: CapabilityExecuteContext
): Promise<StoryboardParseModelOutput>
```

实现要点（`services/storyboardTableParse.ts`）：

1. 输入**仅** `shotRaw`（trim 后为空 → 抛错「请先填写原文」）
2. 调用文字模型时设 `responseMimeType: 'application/json'`（对齐 `geminiService.parsePromptStructured`）
3. 剥 ```json 围栏 → `JSON.parse` → 归一化
4. **不**走 `executeCapability` 的 `【系统任务】`/`【用户文字】` 包装（避免与拖文字卡逻辑耦合）

```ts
parseStoryboardRowWithPreset(
  row, catalog, preset, ctx
): Promise<{ catalog, row }>
// merge catalog → applyShotFieldsPatch → row.shotRaw = input
```

### 5.6 批量解析

| 项 | 规则 |
|----|------|
| 并发 | 最多 2（`mapLimit`） |
| 跳过 | `locked === true` 或 `shotRaw` 为空 |
| 失败 | 该行保留原状；结束后 toast「成功 N / 失败 M」 |
| 部分成功 | 不回滚已成功行 |

### 6.3 行编辑器（`StoryboardTableRowEditor`）

**移除**单一「镜头文本」大 `textarea` 作为主编辑区。

1. **系统区**：镜头号、时长、时间轴轨道（多轨时）
2. **原文区** `shotRaw`：未解析或点「编辑原文」可改；已解析默认折叠
3. **结构化字段区**：按 `fieldCatalog.order` 渲染；**可手改值**
   - 默认展开：`pickPrimaryVisualField` + 前 3 个非空字段
   - 其余：**▸ 更多 N 项** 折叠（百镜虚拟列表控行高）
   - onChange → `applyShotFieldsPatch`
4. **编译预览**（只读折叠）：`shotText`
5. **分镜图区**：不变

## 七、与重绘 / 优化的衔接

### 7.1 重绘（现有 P1）

`buildStoryboardRowPromptText` **改为** `compileRedrawPrompt(row, catalog, promptExtra?)`（或内部转调）。

`redrawRowDisabledReason`：`compileRedrawPrompt` 为空 →「需先解析或填写画面类字段」。

### 7.2 结构化优化（S6）

与解析 **输入输出契约不同**：

**输入**（当前行已有结构，不喂 `shotRaw`）：

```json
{
  "catalog": [{ "id": "f_visual", "label": "画面" }],
  "fields": [{ "id": "f_visual", "value": "…" }]
}
```

**输出**：

```json
{
  "fields": [{ "id": "f_visual", "value": "润色后…" }]
}
```

约束（写在 optimize 预设 instruction）：

- 禁止新增 / 删除 `id`
- 禁止合并字段
- `redrawInclude===false` 的字段（对白等）默认逐字保留，除非用户显式勾选「可改对白」

合并：`applyShotFieldsPatch`；**不**改 `fieldCatalog` 的 id 集合。

## 十一、验收标准

1. 新建分镜表：展开 `shotRaw`；catalog 为空；无大 `shotText` 编辑框。
2. 选解析预设 → 填原文 →「解析本镜」→ 出现动态字段；`shotText` 仅编译预览。
3. 镜 A 解析出「音效」→ 全表多一列；镜 B 音效为空。
4. 改原文再解析：新字段覆盖，**未返回的旧 field id 值保留**。
5. `shotNo` / `durationSec` 不受解析影响；锁定行不可解析。
6. 手改「画面」→ `shotText` 与 `compileRedrawPrompt` 同步；对白不进重绘。
7. 刷新后 `fieldCatalog`、`shotFields`、`shotRaw`、`parsePresetId` 仍在。

## 十四、风险与缓解

| 风险 | 缓解 |
|------|------|
| 同义不同 label | 种子预设 + optimize 契约；后期表级合并工具 |
| catalog 列过多 | 单次 ≤16；全表 >12 软提示；行内折叠 |
| 解析失败 | toast；`shotRaw` 不变 |
| token 成本 | 手动解析；全表确认 |
| instruction 被用户改坏 | 文档声明不保证；筛选推荐 `storyboard_parse_*` id |
| 行高膨胀 | 默认折叠非主视觉字段 |
| 旧 bundle | normalize 迁入 `shotRaw`，不自动 LLM |
