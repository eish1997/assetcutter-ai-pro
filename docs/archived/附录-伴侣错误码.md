# 附录：本地伴侣错误码前缀与占位（已决）

> **约定**：错误响应体建议含 `code`（机器可读）、`message`（人类可读）。前缀与下列占位 **2026-04-27** 起作为默认规范，实现时可扩展。

## 前缀

| 前缀 | 域 |
|------|-----|
| `COMPANION_*` | 宿主 / 通用 |
| `COMPUTE_*` | 计算 Job / Adapter |
| `STORAGE_*` | 卷、manifest、读写 |
| `RELAY_*` | 站点中转 / 连接器 |
| `AUTH_*` | 配对、Token、设备会话（与后端对齐时可细分为 `COMPANION_AUTH_*`） |

## 占位码（与当前实现对齐）

| `code` | 说明 |
|--------|------|
| `COMPUTE_INVALID_BODY` | Job 请求体非法或非 JSON |
| `COMPUTE_BAD_PROTOCOL` | `protocolVersion` 不支持 |
| `COMPUTE_BAD_JOB` | 缺 `type` 等必填字段 |
| `COMPUTE_DUPLICATE` | `jobId` 已存在 |
| `COMPUTE_ADAPTER_NOT_READY` | 已登记 `type` 尚无可运行 Adapter |
| `COMPUTE_UNKNOWN_TYPE` | 未知 `type` |
| `COMPUTE_NOT_FOUND` | Job 不存在 |
| `COMPUTE_SEAM_BACKEND` | 修缝 HTTP 服务不可用或非 PNG 响应 |
| `COMPUTE_SEAM_INPUT` | WebSeamRepair 返回 400（参数/文件非法） |
| `COMPUTE_SEAM_TIMEOUT` | 修缝请求超时（见 `COMPANION_SEAM_REPAIR_TIMEOUT_MS`） |
| `COMPUTE_REMBG_NOT_INSTALLED` | rembg Python 模块未安装（去背景任务或 `probeRembgPythonHealth`） |
| `COMPUTE_REMBG_PYTHON_NOT_FOUND` | `COMPANION_REMBG_PYTHON` 指向的可执行文件不存在 |
| `COMPUTE_REMBG_MODEL` | rembg 模型/会话类错误（stderr 摘要） |
| `COMPUTE_REMBG_FAILED` | rembg 子进程失败或其它未归类错误 |
| `REMBG_PROBE_SPAWN_ERROR` | rembg 探测子进程 spawn 失败 |
| `STORAGE_INVALID_ID` | `projectId` / `key` 非法 |
| `STORAGE_NOT_FOUND` | 项目或 manifest 条目不存在 |
| `STORAGE_INVALID_BODY` | 上传体为空等 |
| `STORAGE_IO` | 读写/删除失败 |
| `PAYLOAD_TOO_LARGE` | 超过 `COMPANION_MAX_UPLOAD_BYTES` |
| `RELAY_NOT_ENABLED` | 本包未启用 Relay（占位） |
| `AUTH_TOKEN_INVALID` | `Authorization: Bearer` 与 `COMPANION_SHARED_TOKEN` 不一致 |
| `AUTH_TOKEN_REQUIRED` | 已启用 `COMPANION_SHARED_TOKEN` 但未带合法 Bearer |
| `AUTH_ORIGIN_DENIED` | `Origin` 不在 `COMPANION_ALLOWED_ORIGINS` 白名单 |

## HTTP 状态码习惯（非强制）

| 场景 | 建议状态码 |
|------|------------|
| 资源不存在 | `404` |
| 请求不合法 | `400` |
| 冲突（重复 jobId） | `409` |
| 体过大 | `413` |

**维护**：新增码时在本表追加一行，并在 `local-companion` 或主站实现处使用同一字符串。
