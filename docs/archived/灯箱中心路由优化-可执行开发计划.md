## Goal

灯箱中心区由**一个可单测函数**决定走 `text` / `media` / `image`；作坊 **package 卡**的视频/3D URL 合并与 loose 对齐；文本通道**不再**把 SVG 占位当 `imageSrc`。

一句话：收拾的是 **WorkflowSection 决策层 + hydrate 不对称**，不是重写灯箱。

## Non-goals

- 不新写第三套灯箱 Viewer。
- 不重写 `ImagePreviewOverlay`（位图引擎：平移缩放、全景、高度场、标注、SAM、Rembg、局部重绘）。
- 不把两条 3D 路径合成一个 Viewer：原生 `model3d` 走 `AssetMediaPreviewCenter`；图卡附 Tripo/Tencent 3D 仍走 `ImagePreviewOverlay` 的 `previewLayout === 'model3d'`。
- 不把 2026-07 的 `AssetPreviewShell` 做成主工具栏、不推进未收口 **C1**。灯箱内已卸掉实验顶栏，只留黑色产品栏。
- 不拆 `WorkflowSection.tsx` 整文件。
- 不改卡片角标、不改宪章货/库口径、不加格式表之外的新格式。
- 不把集合资产（组 / 分镜表 / 资产集）改成灯箱中心路由；它们继续走现有侧栏/面板。
