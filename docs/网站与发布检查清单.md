# 网站与发布检查清单

## 1. 用途

合并 / 发布前：与 **GitHub Actions** 门禁及手测清单交叉引用，避免漏项。

## 2. 手测（工作流「本机四环」）

见 **`docs/工作流步骤时间线审计与Overlay快照.md` §14**（审计环 + Overlay 环：session、scoped local、IndexedDB、`hydrate`）。

## 3. CI（自动化）

- **配置文件**：`.github/workflows/ci.yml`
- **触发**：`push` / `pull_request` 至 **`main` / `master`**；支持 **`workflow_dispatch`** 手动重跑。
- **与四环相关的步骤**：`Typecheck` → **`Workflow rings (audit + overlay IDB / hydrate)`**（`npm run test:workflow-rings`）→ `ESLint` → **`Unit tests (Vitest)`**（`npm test`，全量含同一文件）→ OpenAPI、local-companion typecheck、`guard:storage`、`Production build`。

本地快速只跑四环单测：`npm run test:workflow-rings`。
