本机分割（SamLocal）

网站工作区「本机分割」需要本机运行 SamLocal（127.0.0.1:18081）。在 Windows 上可点击下方按钮，由安装包自动准备 Python、依赖与模型（首次可能需较长时间，请保持网络畅通），无需打开终端。完成后本机会自动重启本地伴侣。
