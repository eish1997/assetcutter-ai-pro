OCR / 文档解析

非 Windows：请安装 Python 3.11+ 后执行 pip install paddlepaddle paddleocr（GPU 版用 paddlepaddle-gpu），设置 COMPANION_PADDLEOCR_PYTHON 并重启伴侣。

非 Windows：请安装 Python 3.11+ 后执行 pip install "rembg[cpu]"，并在启动伴侣的进程中设置 COMPANION_REMBG_PYTHON 为对应 python 路径。
