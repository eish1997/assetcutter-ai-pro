# Override: 工具架（五金铺）

相对 `MASTER.md` 的偏差只在这里。静态预览：[`../preview-tools.html`](../preview-tools.html)。

这一页**不要**做成作坊图墙，也不要「旧卡片 + 顶上一根强调色」。

- 中间是机修铺**影子板**：穿孔背板 + 挂上去的金属铭牌。
- **签名**：选中那一块牌被店灯扫到——左侧一条细钨丝高光。没有黄横条、没有进度条、没有整圈霓虹。
- 已装 = 实心铭牌；未装 = 只剩影子轮廓。
- 左栏是货道标（全部 / 我的 / 本地 / 云端 / 宿主），不是顶上一排 pill。
- 主动作仍是打开 / 下载 / 更新，写在铭牌底部。
- 空态：「板上是空的」。
