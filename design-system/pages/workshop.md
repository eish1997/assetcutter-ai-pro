# Override: 作坊（图墙）

相对 `MASTER.md` 的偏差只在这里。

- 中间图墙是签名落点：选中卡 `ring-1` / `ring-2` 用 `tungsten`，不要蓝角标、不要彩色徽章抢戏。
- 左树保持石墨，不另铺实色底、不画右边框，和图墙同一层波浪底；当前文件夹用字重，折叠用三角，不再画左侧竖条。
- 快捷输入默认横跨中间资产列和右侧功能预设列的上方，独占一行（`data-workflow-canvas-and-sidebar`），不是浮在图墙上的 `fixed` 条。种类筛选、路径、图墙仍只在中间列。灯箱里仍走浮层。发送圆钮兼一键执行：有内容就入队并跑，空输入且有队列则执行队列。输入行与下面内容间距 `gap-2`；顶行底色 `bg-white/[0.04]`，选中种类只用钨丝字重，不铺金底。
- 工作台主按钮（发送/执行）白底黑字 `bg-white text-[#0a0a0c]`，不是 SaaS 蓝，也不是钨丝填色。执行中在圆钮上显示进度。
- 待处理队列在发送钮左侧叠卡；空队列不渲染叠卡。组/移出组/复制/删除/下载与种类筛选同一行右侧对齐，是虚线投放槽（拖资产上去），不是按钮。都不在右侧功能栏。
- 顶行六点抓手弹出独立窗 `ac-quick-compose`（与能力区 `ac-function-sidebar` 可同时存在）；网页无壳退回页内 fixed 浮层。
- 工作台铬件（种类芯片、路径条、组操作、能力卡、筛选芯片）默认不画实线框，用底色/字重区分；拖入高亮和选中图墙卡除外。
- 卡片正面是缩略图；文件名 10–11px `paper`，格式后缀 `quiet` + JetBrains Mono。
- 灯箱是预览，不是第二套皮肤：同样 `ink` / `graphite`，焦点环同样 tungsten。
- 禁止为「第一次进大文件夹」做骨架闪烁以外的装饰动画。
- 空白图墙不画底框、不放彩色新建钮。只告诉新用户三件事：拖入、粘贴、右键新建；前两件用更大字重。
