# Override: 作坊（图墙）

相对 `MASTER.md` 的偏差只在这里。

- 中间图墙是签名落点：选中卡 `ring-1` / `ring-2` 用 `tungsten`，不要蓝角标、不要彩色徽章抢戏。
- 左树保持石墨，不另铺实色底、不画右边框，和图墙同一层波浪底；当前文件夹用字重，折叠用三角，不再画左侧竖条。
- 工作台主按钮（一键执行）对齐底部发送键：白底黑字 `bg-white text-[#0a0a0c]`，不是 SaaS 蓝，也不是钨丝填色。
- 工作台铬件（种类芯片、路径条、组操作、能力卡、筛选芯片）默认不画实线框，用底色/字重区分；拖入高亮和选中图墙卡除外。
- 卡片正面是缩略图；文件名 10–11px `paper`，格式后缀 `quiet` + JetBrains Mono。
- 灯箱是预览，不是第二套皮肤：同样 `ink` / `graphite`，焦点环同样 tungsten。
- 禁止为「第一次进大文件夹」做骨架闪烁以外的装饰动画。
- 空白图墙不画底框、不放彩色新建钮。只告诉新用户三件事：拖入、粘贴、右键新建；前两件用更大字重。
