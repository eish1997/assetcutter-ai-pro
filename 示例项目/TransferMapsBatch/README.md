# 批量传递贴图（TransferMapsBatch）

在 Maya 中**批量**配置多组「低模 → 高模 → 贴图」，仅做**传递**（将高模上已有贴图按低模 UV 重采样输出），不烘焙法线等新图。自带的传递贴图一次只能设一组，本工具提供三列界面，可配置多组后统一执行。

---

## 依赖

- **Maya 2018+**（兼容 Python 2 / Python 3）

---

## 安装

1. 将 `TransferMapsBatch` 文件夹放到 Maya 可访问路径下。
2. 在 Maya **Script Editor** 的 **Python** 栏执行（路径改为本机实际路径）：

   **Maya 2018 (Python 2):**
   ```python
   execfile(r"F:\AI\Code\MayaPlugins\TransferMapsBatch\install.py")
   ```

   **Maya 2022+ (Python 3):**
   ```python
   exec(open(r"F:\AI\Code\MayaPlugins\TransferMapsBatch\install.py", encoding="utf-8").read())
   ```

3. 安装会写入 `userSetup.py` 并创建 **Shelf 按钮「传递贴图」**，点击即可打开工具。

## 界面说明

- **四列：贴图集 → 低模 → 高模 → 贴图**
  - **贴图集**：仅作命名，表示「这一组低模共用一套贴图」。可「添加」并输入名称（如 GunSet、角色A）。一个贴图集下可放多个低模，每个低模可链多个高模及贴图；传递时该集内**所有类型贴图都会传递**（颜色、粗糙度、法线等），输出文件名带贴图集名 + 自动识别的通道后缀，避免混图。
  - **低模**：在当前贴图集下添加目标网格。
  - **高模**：在当前低模下添加源网格。
  - **贴图**：当前「低模+高模」的贴图列表。可**从高模扫描**（全部贴图加入当前集）、拖入或「添加贴图...」。传递时按材质连接通道自动区分输出（如 `GunSet_低模_from_高模_BaseColor_tex.png`）。

- **Maya 公用输出**
  - 贴图宽度/高度、保持纵横比、传入空间、采样质量、过滤器大小/类型、填充纹理接缝、忽略镜像面、翻转 U/V、输出目录。与 Maya 自带传递贴图中的「Maya 公用输出」一致，会持久化到配置。

- **传递**
  - 按**贴图集**依次执行：每个贴图集内的 (低模, 高模, 贴图) 逐张传递，输出文件名带贴图集名、低模名、高模名与通道后缀，如 `GunSet_低模_from_高模_BaseColor_1001.png`，避免多组件共用材质时过程文件互相覆盖。传递完成后高模会恢复为原来的材质；输出目录不存在会自动创建。

- **UDIM / 多 UV 象限**
  - 从 file 节点得到 `<UDIM>` 模板或 `tex.1001.exr` 后，**直接在同目录按文件名扫描**全部 tile（如 `tex.*.exr`），比 mesh UV 推算更快、更准。
  - 已是具体编号的路径原样使用，不会改写成其它 UDIM 编号。
  - 烘焙时仍按 mesh UV 隔离各象限的面；tile 列表以磁盘上实际存在的文件为准。
  - 烘焙某一 tile（如 1001）时，**高模与低模都会临时复制并删掉其它象限的面**，仅该象限参与 surfaceSampler；找不到对应面则跳过该项并写日志。
  - 象限面查找优先用 **OpenMaya `getAssignedUVs` 批量读取**（API 2.0 / 1.0），回退为 `map[*]` + `polyInfo -faceToUV`；同 mesh 同 tile 在整批内缓存结果。

- **整批传递与取消**
  - 点击「传递」后任务分析与烘焙在后台分步执行；进度显示在主窗口标题（如 `3/10`）与底部日志，不再弹出独立进度窗口。
  - 传递过程中主窗口底部显示「取消整批」，可在当前张完成后中止后续任务。
  - 「取消整批」中止本次全部任务；单张 `surfaceSampler` 执行时 Maya 可能短暂无响应，该张完成后立即停止后续任务。

## 概念区分

- **传递**：高模上已有的贴图（文件）按低模的 UV 布局重采样，输出新的贴图文件。不从几何体烘焙法线、置换等。
- **烘焙**：从高模几何体计算法线、置换、AO 等并输出贴图。本工具不做烘焙，只做传递。

## 按 UV 合并为一套贴图（设计说明）

当同一贴图集内有多个低模、且这些低模的 UV 共用一个象限（如 4 个低模拼成一张 0–1 图）时，可以：

- **当前默认行为**：每个「低模–高模」单独传递，得到 N 套贴图（如 4 低模 × 4 张 = 16 张）。
- **合并模式（待实现）**：先对每个「低模–高模」按现有逻辑传递，得到多张图；再在脚本里按「同一通道」把多张合成一套（4 张），每张里包含所有低模 UV 岛的信息。

### 怎么合：先传递，再合成

- **不采用**「直接传递到一张图」：Maya 的传递/烘焙是按「一个低模 + 一个高模 → 一张图」做的，没有多对同时写到同一张图的官方接口；若要做成「直接一张」要么合并成一个低模再按岛区分高模（实现复杂），要么多次写同一文件并按规则覆盖，本质仍是「先传再合」。
- **采用**：先对每个 (低模, 高模) 做传递，得到多张图；再用脚本把这多张合成为一套。实现简单、可维护，且能复用现有传递逻辑。

### 合成方法：按 Alpha 叠加，不做扣黑

- 若传递结果是无信息区域为**黑底**，合成时只能靠「扣黑」（按亮度阈值当透明），容易有锯齿和误判。
- 更好做法：传递时让**无信息区域带透明（Alpha）**，合成时按 Alpha 叠加（如 over），这样不用在 PS 里扣黑，也不容易出问题。
- 实现思路：
  1. **每张传递结果**：在写出时附带 Alpha——用「低模 UV 覆盖 mask」（低模赋白、surfaceSampler 从低模采到低模自身 UV，得到白/黑图）作为 Alpha，与传递得到的 RGB 合成后写出为带 Alpha 的 PNG。
  2. **合成**：同一通道的多张图（每张已是「有信息处不透明、无信息处透明」）按顺序 **over 叠加**成一张，得到最终一套贴图（如 4 张：BaseColor / Roughness / Normal / Metallic）。
- 这样无信息区域是透明或有 Alpha，无需扣黑，避免扣图带来的边缘和阈值问题。

## 配置持久化

配置保存在 Maya 用户目录下，例如：`文档/Maya/2022/TransferMapsBatch/transfer_maps_batch_config.json`，包含公用输出相关项及输出目录，下次打开工具时自动加载。
